# Créditos y licencia

Esta skill es una **adaptación en español, condensada y reorganizada** del sistema de diseño **Astryx** de Meta Platforms:

- Repositorio original: https://github.com/meta/astryx
- Documentación: https://astryx.atmeta.com
- Versión de referencia al escribir esta skill: `@astryxdesign/core` 0.7.17 (Beta, React 19+, StyleX), commit `eeb3d7c` del 2026-11-14.

Qué se tomó: principios de diseño, reglas de layout, valores de tokens, catálogo de componentes y reglas de uso, rúbrica de revisión, flujo con el CLI. Qué es propio: la estructura en una skill, las tablas de decisión, el flujo de siete pasos, el contrato de entrega, el auditor `scripts/auditar-ui.mjs` y la redacción en español. Los ejemplos de código son versiones cortas de los de la documentación original. Para el detalle exacto de una API, la fuente de verdad es siempre el paquete instalado (`astryx component <Nombre> --dense`), no esta skill.

Astryx es Beta: nombres, props y tokens pueden cambiar. Si la versión del proyecto no es 0.7.x, confirma con el CLI antes de copiar un valor.
